# Java Tutor

Interactive Java practice for **INT100 Introductory Programming** and **INT201 Object Oriented Programming**, Ajman University, Information Technology Department.

**Open the platform:** https://mohammadnawaiseh.github.io/java-tutor/

## What it offers
- **Two courses** with a switcher at the top of the menu: 12 INT100 units and 7 INT201 units, each tagged with its course learning outcome.
- **In every unit:** notes, a step-through lab that shows variables, memory and console output as code runs, practice in eight formats (quick check, flashcards, trace the output, trace table, find the errors, fill the blanks, arrange the code, write the code), and a one-page cheat sheet.
- **Study tools for each course:** common mistakes with the real Java messages, lab walkthroughs where students write and test their own solutions, lab exam practice papers, and a timed mock exam with results by CLO.

## Notes
- The whole platform is the single file `index.html`; no server or login is needed.
- Each student's progress and code drafts are stored only in their own browser.
- To update the site, replace `index.html` with a new version and commit.
